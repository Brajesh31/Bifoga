## Maintainer responsibilities

- Keep the default branch usable.
- Review proposed code and documentation changes.
- Protect visitor privacy and repository secrets.
- Keep dependencies and GitHub Actions under review.
- Verify release contents and public claims.
- Maintain accurate support and security-reporting instructions.

## Becoming a maintainer

Maintainer access is granted by the repository owner based on sustained, trustworthy contributions and demonstrated understanding of the project. It is not automatically granted by opening issues or pull requests.

## Contact and escalation

Use the repository's public support process for normal questions. Use the private reporting process in `SECURITY.md` for vulnerabilities. Do not publish credentials or personal data in public discussions.
