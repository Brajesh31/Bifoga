# 🖼️ Asset Library

This directory is reserved for project-owned visual assets that are actually used by the website or documentation.

## Organization

- `banners/`: approved repository or social-preview banners.
- `logos/`: logo variants and source artwork.
- `screenshots/desktop/`: genuine desktop captures of the running site.
- `screenshots/mobile/`: genuine mobile viewport captures.
- `diagrams/`: exported diagram images when a rendered image is useful in addition to editable Mermaid source.
- `charts/`: measured data visualizations with source and date.
- `illustrations/`: original supporting illustrations.
- `demos/`: short demonstration media.

## Asset rules

1. Do not add stock images as if they were screenshots of this project.
2. Do not fabricate product states, dashboards, metrics, or user testimonials.
3. Preserve the existing logo at `docs/img/logo.png`; do not replace it without approval.
4. Add meaningful alternative text wherever an image is embedded in HTML.
5. Optimize images for their actual display dimensions.
6. Record provenance and licensing for third-party assets.
7. Prefer editable Mermaid source in `docs/diagrams/` for technical diagrams.

Directories are created when real assets are added. Empty placeholder folders are intentionally not committed.
