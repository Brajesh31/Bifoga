# Security Policy

EnClose is a static prototype. It has no server-side contact processing, authentication, database, or secrets. The form target is not implemented in this repository, so do not submit personal, business-confidential, or credential information.

Before production use, add server-side validation, spam protection, consent and retention controls, HTTPS, security headers, and an explicit privacy policy. Pin or self-host external dependencies where appropriate.

Report security issues privately to Brajesh Kumar through <https://github.com/brajesh31>. Do not include sensitive form data in public issues.
