# Development

Edit page markup in `docs/index.html`, behavior in `main.js`, and Tailwind input in `src/input.css`. `docs/style.css` is generated output; regenerate it after changing Tailwind input.

Check navigation anchors, service tabs, text wrapping, image loading, mobile layout, keyboard focus, and the contact form target using a local server. Keep contact examples synthetic.

Run `npm run prettier` when formatting HTML changes.
