# 🗺️ Diagram Catalogue

This directory stores editable Mermaid source diagrams. GitHub renders Mermaid in supported Markdown contexts, so the source remains reviewable and maintainable without committing fabricated screenshots or unverified exports.

| Diagram | Purpose | Status represented |
|---|---|---|
| `system-context.mmd` | Static website boundary and visitor | Current architecture |
| `page-navigation.mmd` | Page navigation and section movement | Current page concept |
| `form-boundary.mmd` | Contact form and missing endpoint boundary | Current limitation plus future branch |
| `asset-delivery.mmd` | Browser asset loading | Current static delivery |
| `development-workflow.mmd` | Local edit, Tailwind and preview workflow | Current development process |
| `future-service-integration.mmd` | Safe shape of a future server integration | Proposed, not implemented |

To use a diagram in Markdown, embed its source in a fenced `mermaid` block or link to the source file. Keep labels accurate and update diagrams whenever the implementation changes.
