# 🧰 Operational Runbooks

Runbooks provide repeatable steps for common maintenance tasks. They are written for the current static-site repository and do not assume a backend or production deployment provider.

| Runbook | Use when |
|---|---|
| [Local preview](local-preview.md) | Starting a local development preview |
| [Static release](static-release.md) | Preparing and verifying a static release |
| [Incident response](incident-response.md) | Responding to a broken page, exposed secret, or suspected compromise |

Record the actual host, deployment owner, and recovery access procedure in a private operational system if those details should not be public.
