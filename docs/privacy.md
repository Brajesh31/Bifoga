# 🛡️ Privacy Considerations

## Current data collection

The repository contains a static landing page and a contact form layout. No project-owned form handler, database, account system, or analytics integration is present in the reviewed source. The current form action is a placeholder and must not be described as a working submission channel.

## Privacy principles for future changes

1. Collect only information needed for a clearly stated purpose.
2. Explain the purpose before collecting information.
3. Avoid sensitive personal or business-confidential fields unless strictly necessary.
4. Restrict access to any received enquiries.
5. Define retention and deletion periods before launch.
6. Protect data in transit and at rest where stored.
7. Avoid placing personal data in URLs, analytics events, or application logs.
8. Provide a contact path for privacy questions and requests.

## Before enabling a form

Document the data controller/owner, fields, purposes, lawful basis where applicable, recipients/processors, retention, deletion process, security controls, and incident response. Use server-side validation and abuse controls. A browser-side required attribute is not a privacy or security control.

## Third-party resources

The page currently loads external styling/font resources. Review their privacy implications, request metadata, availability, and whether self-hosting is preferable.

## Review trigger

Update this guide whenever a new external service, analytics tool, cookie, form handler, booking system, AI provider, or persistent store is introduced.
