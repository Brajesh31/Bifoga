# 📖 Glossary

| Term | Meaning in this repository |
|---|---|
| Static site | HTML, CSS, JavaScript and assets served as files without a project-owned application server |
| Browser-side JavaScript | Code executed by the visitor's browser |
| DOM | Document Object Model, the browser's in-memory representation of the page |
| Tailwind CSS | Utility-first CSS framework used by the project tooling |
| Tailwind watcher | Development process that regenerates CSS as source files change |
| Source stylesheet | Authored CSS entry point at `src/input.css` |
| Generated stylesheet | CSS output written to `docs/style.css` by the configured Tailwind command |
| Content glob | File pattern telling Tailwind which files to scan for class names |
| npm | Node.js package manager used to install project development dependencies and run scripts |
| Lockfile | `package-lock.json`, which records the resolved dependency tree |
| Static host | Service that serves the built website files over HTTP/HTTPS |
| Endpoint | A network address and method handled by a server; no application API endpoint is currently defined here |
| Form handler | Server or service that receives and processes submitted form data; not present in this repository |
| Mermaid | Text-based diagram syntax rendered by compatible Markdown viewers |
| CI | Continuous Integration, automated checks run when repository changes are pushed or opened |
| CD | Continuous Delivery/Deployment, automated preparation or publication of a release |
| CSP | Content Security Policy, a browser-enforced restriction on allowed resource sources and execution |
| LCP | Largest Contentful Paint, a Core Web Vitals loading metric |
| CLS | Cumulative Layout Shift, a visual stability metric |
| INP | Interaction to Next Paint, a responsiveness metric |
| WCAG | Web Content Accessibility Guidelines |
| ADR | Architecture Decision Record, a short document capturing a technical decision and its rationale |
| DFD | Data Flow Diagram, a representation of data moving between actors and system processes |
| Threat model | A structured analysis of assets, trust boundaries, threats and mitigations |
