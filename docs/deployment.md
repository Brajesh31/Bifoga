# Deployment

Deploy the contents of `docs/` to a static HTTPS host. Ensure the host serves `index.html` at the site root and serves `/style.css` and `/img/logo.png` at their expected paths.

The current contact form points to `/action_page.php`, which is not implemented here. Configure a reviewed backend endpoint before advertising submissions. Add security headers, HTTPS, privacy notices, validation, and spam protection for production.
