# FAQ

## Is EnClose a full AI service?

No. It is a static marketing prototype describing consultation and education services.

## Does it store contact messages?

No backend or database is included.

## How do I preview it?

Run `npx serve docs` after installing dependencies.

## Where is the page logic?

The service-tab helper is in `main.js`; page markup is in `docs/index.html`.

## Where should security issues be reported?

Use the private process in [SECURITY.md](../SECURITY.md).
