# 🆘 Support

Bifoga / EnClose is maintained on a best-effort basis. The current repository is a static landing-page project, not a hosted AI consultation or booking service.

## Before opening an issue

1. Read the [README](README.md).
2. Follow [installation](docs/installation.md) and [local preview](docs/runbooks/local-preview.md).
3. Check the [FAQ](docs/faq.md) and [troubleshooting guide](docs/troubleshooting.md).
4. Search existing issues before opening a duplicate.

## What to include

- Browser and version.
- Operating system and viewport size.
- Exact local command used.
- Page section or file affected.
- Steps to reproduce.
- Sanitized console/network output.
- Genuine screenshots where useful.

## What not to include

Do not attach passwords, API keys, personal contact submissions, private customer information, or confidential business data.

## Security reports

Do not open a public issue for a suspected vulnerability. Follow [SECURITY.md](SECURITY.md).
