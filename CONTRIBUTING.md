# Contributing

Keep contributions focused on the static landing page and use synthetic contact data.

1. Create a focused branch.
2. Install with `npm ci`.
3. Run a local static server and test navigation, service tabs, assets, and form behavior.
4. Rebuild generated CSS when changing Tailwind input.
5. Keep external URLs, accessibility, and responsive behavior documented.

Pull requests should include verification steps and screenshots for visible changes. Report vulnerabilities privately using [SECURITY.md](SECURITY.md).
